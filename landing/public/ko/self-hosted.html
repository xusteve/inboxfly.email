FAQ

자주 묻는 질문

데이터는 어디에 저장되나요?

내 Cloudflare 계정 안(D1·R2·Worker 모두 내 것). 패널은 인터페이스일 뿐이며 API를 해지해도 데이터는 남습니다.

비용은?

소프트웨어 무료(MIT). Cloudflare 무료 티어에서 동작: Workers 10만 요청/일·D1 5GB·R2 10GB·Email Routing 무료.

스팸 처리되지 않나요?

Cloudflare 자체 인프라에서 SPF 정렬하여 전달. 최종 수신함 배치는 어떤 전달 서비스도 관측할 수 없습니다.

메일을 InboxFly에 맡겨야 하나요?

아니요. 배포 후 메일은 내 계정의 Worker를 직접 통과합니다. 패널 토큰을 해지해도 전달은 계속됩니다.

Cloud 버전과 자체 호스팅 차이?

자체 호스팅(이 페이지)은 내 계정에서 무료. Cloud 버전(AI 분석 포함)은 곧 공개 예정.
