FAQ

Frequently asked questions

我的数据存在哪里？

在你自己的 Cloudflare 账号里——D1 数据库、R2 存储和 Worker 都属于你。InboxFly 面板只是一个界面；随时撤销其 API 访问，数据原地不动。

要花多少钱？

软件免费（MIT）。一切运行在 Cloudflare 免费额度内：Workers 每天 10 万请求、D1 5GB、R2 10GB 存储、Email Routing 免费。超出部分按 Cloudflare 标准费率计费。

转发会不会进垃圾箱？

Cloudflare Email Routing 通过其自有基础设施转发并校准 SPF，送达率总体良好；文档同时提供收件侧白名单指引。注意：「已转发」指 Cloudflare 受理了转发，最终落箱位置任何转发服务都无法观测。

需要把邮件托付给 InboxFly 吗？

不需要。部署完成后，邮件直接流经你账号里的 Cloudflare Email Routing 与 Worker。面板只负责配置管理与展示存储副本——撤销其 API Token，转发管道照常运行。

Cloud 版与自部署版？

自部署版（本页介绍）免费运行在你自己的账号里。InboxFly Cloud——托管版，附 AI 分析等增强功能——即将推出。上线后本站将切换为 Cloud 版首页。
