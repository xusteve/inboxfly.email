FAQ

Questions fréquentes

Où sont stockées mes données ?

Dans votre propre compte Cloudflare — D1, R2 et le Worker vous appartiennent. Le panneau n'est qu'une interface ; révoquez son accès API et vos données restent.

Combien ça coûte ?

Le logiciel est gratuit (MIT). Tout fonctionne dans le niveau gratuit Cloudflare : 100k requêtes Worker/jour, D1 5Go, R2 10Go, Email Routing gratuit.

Le transfert finit-il en spam ?

Cloudflare transfère via sa propre infrastructure avec SPF aligné. Le placement final dans la boîte de réception n'est observable par aucun service de transfert.

Dois-je confier mes e-mails à InboxFly ?

Non. Une fois déployé, les e-mails passent directement par le Worker de votre compte. Révoquez le token du panneau et le transfert continue.

Cloud vs auto-hébergé ?

L'auto-hébergé (cette page) est gratuit dans votre compte. InboxFly Cloud (avec analyse IA) arrive bientôt.
